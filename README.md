# Cambridge Institute Website Redesign

Modern, high-performance, accessible redesign for **Cambridge Institute** (https://www.cambriz.com) built with Vite, TypeScript, and the official Cambridge Institute Frontend Design System.

## Features
- **Design System Tokens:** Strict adherence to Primary Navy (`#0C1A45`), Study Abroad Teal (`#0B6A56`), Coaching Mustard Gold (`#C99712`), Canvas (`#F7F6F2`), Surface (`#FFFFFF`), and Inter typography.
- **26 Fully Redesigned Pages:** Covering Institutional Core, Study Abroad, Language Coaching (IELTS, TOEFL, Spoken English, French, German), Visa Services, Tours, and Centers.
- **Responsive Navigation:** Aligned brand wordmark, centered navigation with active underline indicator, desktop action buttons, and accessible mobile drawer.
- **100% Link Integrity:** Automated link validator checking all 2,820 internal links.
- **Zero-Bloat Performance:** Sub-second production builds and lightning-fast loading.

## Development
```bash
npm install
npm run dev
```

## Build & Test
```bash
npm test         # Validates all 2800+ internal links
npm run build    # Produces production bundle in dist/
npm run preview  # Previews production build
```
